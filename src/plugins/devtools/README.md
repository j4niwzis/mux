# devtools

A plugin of [mux](https://github.com/j4niwzis/mux).

The developer tools, as Element's: a message's source, from its menu; a room's state and account data explored and written, and an event of any type sent, from the room's settings. Over Matrix. Built where MUX_PLUGIN_DEVTOOLS is on.
