# display

A plugin of [mux](https://github.com/j4niwzis/mux).

How the window moves and is drawn: Settings' Animations page (full, reduced, none) and Rendering page (OpenGL or software, the frames' switches). Built where MUX_PLUGIN_DISPLAY is on; its settings are its own (contract::settings_kept); without it, the file keeps them as they were, and the window is drawn with OpenGL.
