# emoji_picker

A plugin of [mux](https://github.com/j4niwzis/mux).

The emoji panel, the media panel: its emoji, and the pages plugins give it (stickers, GIFs) -- opened from the chat's input or a thread's, docked under a finger. Built where MUX_PLUGIN_EMOJI_PICKER is on. The emoji kept and their grid are the client's: messages and reactions draw them either way.
