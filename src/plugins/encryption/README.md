# encryption

A plugin of [mux](https://github.com/j4niwzis/mux).

End-to-end encryption for Matrix: the account made with it -- Olm and Megolm (loom.crypto, on vodozemac), emoji verification, cross-signing, the key backup and secret storage -- in place of the client's plain one, which reads no encrypted message and sends nothing into an encrypted room. Built where MUX_PLUGIN_ENCRYPTION is on, and Matrix with it: it is Matrix's encryption, nothing without it.
