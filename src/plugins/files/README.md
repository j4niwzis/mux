# files

A plugin of [mux](https://github.com/j4niwzis/mux).

What is done to a picture dropped on the window before it is sent: Settings' Files page, and the settings it keeps as its own (metadata removed, the file renamed). Built where MUX_PLUGIN_FILES is on; without it, pictures are sent as they are.
