# forums

A plugin of [mux](https://github.com/j4niwzis/mux).

Forums: a space shown as one chat in the chat list, its rooms in it as topics, as Telegram's -- or a protocol's own forum -- chosen in a space's settings and kept as the plugin's own. Built where MUX_PLUGIN_FORUMS is on; without it every space is a space.
