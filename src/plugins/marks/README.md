# marks

A plugin of [mux](https://github.com/j4niwzis/mux).

Telegram's @ and heart: the mentions of the user and the reactions to their messages not seen yet -- kept on disk across runs, their buttons over the list's corner, gone to, listed, and the mentions seen shared with the account's other sessions where its protocol does. Built where MUX_PLUGIN_MARKS is on.
