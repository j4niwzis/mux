# new_room

A plugin of [mux](https://github.com/j4niwzis/mux).

Create a room, as Element's CreateRoomDialog: a name, a topic, who can join, the address it is found by, encryption and federation -- from the drawer, or a space's menu (a room or a space made in it). Built where MUX_PLUGIN_NEW_ROOM is on.
