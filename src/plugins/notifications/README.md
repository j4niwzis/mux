# notifications

A plugin of [mux](https://github.com/j4niwzis/mux).

Notifications: what is told of outside the chat in view -- a message come, an invite -- by the desktop's notifications or mux's own, with the chime, as the settings say; a notification's actions (its chat opened, read, answered); and UnifiedPush, which wakes mux for them. Built where MUX_PLUGIN_NOTIFICATIONS is on.
