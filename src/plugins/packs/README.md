# packs

A plugin of [mux](https://github.com/j4niwzis/mux).

Emojis & Stickers, as Cinny edits them (MSC2545): one's own pack, from Settings and an account's page; a room's, from its settings -- listed, opened, edited, saved, deleted, added to one's account, and images uploaded for them. The packs in use -- custom emoji and stickers in chats, the pickers -- are the client's own. Built where MUX_PLUGIN_PACKS is on.
