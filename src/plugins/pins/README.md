# pins

A plugin of [mux](https://github.com/j4niwzis/mux).

Pinned messages, as Telegram shows them: the bar under a chat's head, the pin above the view, pressed to go to it and swiped through; Pin and Unpin in a message's menu, written as the room's state over Matrix. Built where MUX_PLUGIN_PINS is on.
