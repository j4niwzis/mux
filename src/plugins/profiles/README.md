# profiles

A plugin of [mux](https://github.com/j4niwzis/mux).

An account's Profile page: its name, pronouns, biography and banner, and its presence, as its protocol has them. Built where MUX_PLUGIN_PROFILES is on; the profiles themselves -- people's cards -- are the client's either way.
