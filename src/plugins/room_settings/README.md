# room_settings

A plugin of [mux](https://github.com/j4niwzis/mux).

A room's or a space's settings: the dialog, its tabs -- the client's General, Notifications and Appearance, and those other plugins give it through its own contracts (room_admin's, packs', devtools') -- and its part. Built where MUX_PLUGIN_ROOM_SETTINGS is on; without it, Manage opens nothing.
