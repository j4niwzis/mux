# start_chat

A plugin of [mux](https://github.com/j4niwzis/mux).

Start chat, as Element's: who to talk to, found as it is typed -- among those one already chats with, and in the server's directory -- and one's own link to send; the same dialog inviting someone to a room. Built where MUX_PLUGIN_START_CHAT is on.
