# storage

A plugin of [mux](https://github.com/j4niwzis/mux).

What mux keeps, and how: Settings' Storage page (the seal, the limits in memory and on disk, clearing, deleted messages, room events). Built where MUX_PLUGIN_STORAGE is on; without it, the limits are the defaults.
