# suggestions

A plugin of [mux](https://github.com/j4niwzis/mux).

The list over the chat's composer, as Telegram's: the members matching what follows an @, or the emoji matching what follows a ':' -- Up and Down through it, Enter, Tab or a press picks, Esc closes it. Built where MUX_PLUGIN_SUGGESTIONS is on.
