# threads

A plugin of [mux](https://github.com/j4niwzis/mux).

Threads, as Element's panel: the room's threads listed in the info's place, one opened -- its root and answers as the chat's own list has its messages, and a field to answer in it -- and the button in the chat's head. Built where MUX_PLUGIN_THREADS is on.
